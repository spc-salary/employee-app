# حاسبة الإضافي

تطبيق Flutter أصلي باللغة العربية لحساب مستحقات الإضافي لموظفي مديرية غاز جنوب المنطقة الوسطى. التطبيق لا يستخدم WebView ولا يحتاج إلى خادم أو مفاتيح سرية.

## الوظائف

- اختيار طبيعة الدوام: صباحي أو ورادي.
- اختيار فئة الموظف من الفئات 1 إلى 5، مع عرض سقف كل فئة.
- إدخال راتب التعويضات وساعات الإضافي 5% والنهاري والليلي.
- حساب المبالغ وفق قواعد الملف الأصلي، مع تطبيق سقف 5% على بند الإضافي 5% فقط.
- عرض البنود غير الصفرية والمجموع الكلي وشرح خطوات الحساب.
- التبديل بين الوضعين الفاتح والداكن وإعادة تعيين المدخلات.
- فتح رابط الموقع الأصلي من عنوان التطبيق.

## قواعد الحساب

- قيمة ساعة الأساس = راتب التعويضات ÷ 225 للدوام الصباحي، أو ÷ 180 للدوام الورادي.
- الإضافي 5% = قيمة ساعة الأساس × 1.25 × ساعات 5%، وبحد أقصى 5% من سقف الفئة.
- الإضافي النهاري = قيمة ساعة الأساس × 1.25 × الساعات النهارية.
- الإضافي الليلي = قيمة ساعة الأساس × 1.50 × الساعات الليلية.
- المجموع = الإضافي 5% بعد السقف + الإضافي النهاري + الإضافي الليلي.

| الفئة | سقف الإضافي 5% |
| --- | ---: |
| 1 | 704.50 ل.س |
| 2 | 621.50 ل.س |
| 3 | 592.50 ل.س |
| 4 | 592.50 ل.س |
| 5 | 549.00 ل.س |

## التشغيل محلياً

1. ثبّت Flutter SDK المستقر وAndroid SDK وJDK 17.
2. افتح مجلد `overtime-calculator`.
3. نفّذ:

   ```sh
   flutter pub get
   flutter run
   ```

## الفحص والبناء

```sh
flutter analyze
flutter test
flutter build apk --release
```

ملف APK الناتج محلياً:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## بناء APK عبر GitHub Actions

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. ادفعها إلى فرع `main` أو `master`، أو شغّل سير العمل يدوياً من تبويب **Actions**.
3. بعد نجاح **Build Android APK**, نزّل `overtime-calculator-apk` من قسم **Artifacts** في صفحة التشغيل.

يبني سير العمل نسخة release موقعة بمفتاح debug الافتراضي لأغراض الاختبار فقط؛ هذا ليس مفتاح نشر متجر. إذا كان المطلوب نشر التطبيق على متجر أو توزيع نسخة موقعة رسمياً، أضف إعدادات التوقيع إلى GitHub Secrets بنفسك؛ لا تضع كلمات مرور أو مفاتيح توقيع في المستودع.
